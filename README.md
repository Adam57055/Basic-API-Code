# Overview
This code gives the fundamentals of using AI in applications to obtain sophisticated answers for the user.

## What It Does
The block of code shows the import of the AI model. It does not necessarily have to be an OpenAI api key. It can be any AI model as long
as it is implemented appropriately like shown. There is context given to the AI to give a general idea to them and a prompt for a sample
response to test its effectiveness.
